About

Fast developer tools that respect your workflow.

ToolkitBox is a collection of focused browser tools for formatting data, encoding text, generating identifiers, checking URLs, comparing text, inspecting SSL certificates, and working with colors.

What we build

Each tool is designed to open quickly, stay understandable, and avoid unnecessary account gates. Most processing runs locally in your browser so snippets, payloads, and test data do not need to leave your device.

How the site is organized

The main domain is the directory for developer tools. Individual tools live on subdomains such as json.toolkitbox.org, base64.toolkitbox.org, and ssl.toolkitbox.org.
